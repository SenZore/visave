Video saver for Firefox · Windows x64 · preview 0.3.2

If setup just opened this page, the Windows companion is installed. Continue with step 3.

  1. Extract the entire setup ZIP before running anything. Optionally scan the extracted folder with Windows Security.
  2. Double-click Setup.cmd. Wait for “Installation complete.” Setup checks files and tests MP4/MP3 conversion before registering the companion with Firefox. The bundle includes its own tools, so you do not need separate dependency installers or administrator access.
  3. In Firefox 140 or newer, open about:debugging#/runtime/this-firefox, click Load Temporary Add-on, and select visave-firefox-0.3.2.zip from this folder. Remove an older temporary Video Lens add-on first. You must load this unsigned preview again after restarting Firefox.
  4. Open visave, then Settings > Installation > Check installation. Look for “Installation ready.”
  5. Settings > Save downloaded files to > Choose folder. Future downloads save there without dialogs or automatic File Explorer opening.
  6. Open a video you have permission to download, start playback, refresh the page if needed, and choose MP4 or MP3 in the Now playing row. Play the saved file to check the result.

What gets installed?

Setup needs internet access to download the pinned FFmpeg package directly from the Gyan build publisher. It checks the package and both executable hashes before running the tools. The visave ZIP includes private Python, Node.js, yt-dlp and the setup scripts; it does not contain FFmpeg executables.

Setup writes to the current user's application folder under %LOCALAPPDATA%\senzdev\visave and registers one Firefox native-messaging entry. Firefox launches the companion on demand. Setup adds no startup task, server, or background service.

Python runs yt-dlp; yt-dlp extracts media URLs; FFmpeg combines audio/video and converts formats; FFprobe inspects media; Node runs YouTube challenge code. EJS supplies yt-dlp's challenge implementation. Your system Python and Node installations are not changed.

Verification and sources

This bundle is unsigned and not independently audited. No hash or test proves “not a virus.” Review Install.ps1, Uninstall.ps1 and app/host.py. SHA256SUMS.json records every distributed file; app/UPSTREAM-DOWNLOADS.json and app/DEPENDENCIES.json document source URLs, versions and hashes. Setup refuses altered files. Node and FFmpeg downloads are checked against publisher hashes; the Python executable's Authenticode signature is checked during the build. Licenses ship alongside dependencies.

For an optional verification-only check, open PowerShell in this folder and run powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -VerifyOnly. The policy argument runs the supplied readable script; it does not persistently change Windows' execution policy. Corporate security policy may still block unsigned scripts.

Sources: Python · yt-dlp · EJS · FFmpeg · Gyan Windows build · Node.js.

Limits, updates and uninstall

“Installation ready” confirms components, not every website. DRM-protected videos and active live streams are unavailable. Login restrictions, unusual players, and website changes can still cause failures. Use visave's Supported sites page to search the imported upstream list.

You can get this preview from the visave GitHub release. A permanent Firefox release still needs Mozilla signing. There is no signed Add-ons listing yet. An installer cannot bypass Firefox's signature requirement.

The companion receives the selected URL, download options, and save path. It contacts the selected website and its media hosts. Optional Firefox login access uses the most recently updated Firefox cookie database among the profiles yt-dlp finds. This may differ from your open profile. Container cookies are excluded; relevant login cookies go to the selected website. Privacy details · Website terms and release rules.

To upgrade, finish active downloads, run Setup.cmd from the new bundle and reload visave. Failed component checks preserve the existing registration. Prior installed versions are retained until uninstall so active older processes are not deleted. To remove the companion, close active downloads and run Uninstall.cmd. Downloads remain untouched; remove the Firefox extension separately.
