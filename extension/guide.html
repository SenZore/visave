Install the download components once. Visave checks them and enables downloads when they are ready.

1. Install on Windows

For x64 Windows 10 and 11. Internet access is required.

  1. Click Install dependencies. Open visave-setup-0.3.3.exe from Firefox Downloads when it finishes.
  2. In the setup window, click Install. It installs private Python, yt-dlp, Node.js and video tools for your Windows user. You do not need separate dependency installations, terminal commands or administrator access.
  3. Wait for Installation complete. Return here: the check runs automatically while this page is open. Firefox cannot run a native installer for you. Windows may show its normal warning because this preview installer is unsigned.

Prefer the readable scripts? Download the ZIP bundle, extract it, and run Setup.cmd. The installer source is public under setup/Bootstrap.cs.

Alternatively, open PowerShell and run this command. It downloads and runs the published installer, verifies the Windows bundle against its release checksum, then opens the Firefox setup guide. Read the installer first.

irm https://raw.githubusercontent.com/senzore/visave/v0.3.3/install.ps1 | iex

2. Add visave to Firefox

This release is an unsigned development build. Open about:debugging#/runtime/this-firefox, click Load Temporary Add-on, and select the visave extension ZIP inside the setup bundle. Temporary installation lasts until Firefox closes; repeat this step after restart. Remove an older temporary Video Lens installation first.

A permanent, install-and-use release requires Mozilla signing. There is no signed Firefox Add-ons listing yet. About signing.

3. Check installation

Checks the Firefox connection, downloader, video tools, and YouTube runtime.

    4. Choose a save folder

    Open visave → Settings → Save downloaded files to → Choose folder. Choose once. MP4 and MP3 downloads then save there without save dialogs or automatic File Explorer opening. Click the path to change it, or Clear to restore save dialogs.

    5. Try a download

    Open an individual YouTube video or Instagram reel and start playback. Refresh the page after adding the extension. In visave use the Now playing row, choose MP4 or MP3, and press Download. Open the arrow menu for quality and options. Check the saved file plays correctly. Instagram files receive random names.

    Installation ready means the required tools can run. It does not mean every website or video will work. DRM-protected media and active live streams are unavailable. For videos needing login, select Use my Firefox login only if you want the local downloader to read your Firefox cookies for that download. Private-window and container logins are unsupported.

    Why these components?

    Python
    Runs the local download application and yt-dlp. The bundle includes a private runtime rather than changing your system Python.
    yt-dlp + EJS
    Finds media streams on supported websites and handles YouTube's JavaScript challenges.
    FFmpeg + FFprobe
    Combines video and audio, converts MP3/MP4 when required, and inspects output. Setup downloads the pinned Windows package from the Gyan build project linked by FFmpeg, then checks the package and executable hashes.
    Node.js
    Runs the YouTube challenge code through yt-dlp. It does not install a server or run continuously.

    Inspect before installing

    The setup bundle contains readable setup scripts, application source, dependency licenses, a dependency report with download URLs, and SHA-256 hashes. Setup checks every listed bundled file before running the runtime. The build verifies Node and FFmpeg downloads against publisher hashes and Python's executable signature.

    Hashes show that files match the bundle manifest; they do not prove a program is harmless. This development bundle is not code-signed and has not been independently security audited. You can inspect the scripts and scan the extracted folder with Windows Security before running Setup.cmd. No claim of “virus-free” is made.

    Firefox launches the companion when visave needs it. Website access lets visave inspect players while enabled; downloads permission saves files; native messaging connects the local tools. The companion receives the selected URL, download options, and save path. It sends media requests to the selected website and its media hosts. If you select Use my Firefox login, yt-dlp reads the most recently updated Firefox cookie database, which may belong to another profile. It excludes container cookies and sends relevant login cookies with download requests. Visave has no analytics or developer server. Read how visave handles data.

    Download only media you own or have permission to save. A working extractor does not grant permission under a website's terms. Release rules and website terms.

    Repair or remove

    Close active downloads before upgrading. Run Setup.cmd from a new bundle to repair or upgrade, then reload the extension to reconnect. Site support can change; use an updated bundle when yt-dlp needs an update. Uninstall.cmd removes the registered companion and its installed files, preserving your downloaded videos and audio.
